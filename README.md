# Abel Site · Para mi Ale

Una web de nueve meses para Alexandra Isabel, de Abel. Diseño en azul noche, marfil y dorado suave.

Nombre sugerido para el repositorio de GitHub: `abel-site`.

Incluye diez fotografías, viajes a Cangallo, Cajamarca y Lima, nueve motivos para descubrir, la carta de aniversario, cuatro sobres «Ábreme cuando», una melodía instrumental original opcional, una canción para buscar en YouTube, ocho planes y una sorpresa final.

## Abrirla en la computadora

Abre `index.html` dentro de la carpeta que contiene la web. Se puede abrir directamente, sin instalar programas. Todos los archivos de `assets`, `style.css` y `app.js` deben permanecer junto a ese archivo.

## Publicarla en GitHub Pages

1. Crea o selecciona el repositorio donde quieres publicar la web.
2. Sube el **contenido** de la carpeta de la web. `index.html` debe quedar en la raíz del repositorio, junto a `style.css`, `app.js`, `.nojekyll` y `assets`.
3. En GitHub, entra a **Settings → Pages**.
4. Selecciona **Deploy from a branch**, la rama **main** y la carpeta **/(root)**. Guarda.
5. Espera a que GitHub termine la publicación y utiliza el enlace que muestre allí.

El sitio publicado con GitHub Pages y sus fotografías serán accesibles por su dirección. La etiqueta `noindex` solicita a los buscadores que no lo indexen; no establece una contraseña.

## Personalización

- Los textos y las fotos están en `index.html`.
- Los sobres, los planes y la sorpresa final están en `app.js`.
- Los colores y el diseño están en `style.css`.
- El piano se activa solamente al pulsar su botón y se pausa al salir de la pestaña. La canción de Camila tiene un enlace de búsqueda; no se ha incluido una grabación.
- No se ha supuesto una fecha de inicio ni una fecha de reencuentro. Se celebra el noveno mes sin mostrar un contador con fechas inventadas.
- Las fotos no están etiquetadas por ciudad, porque no se ha confirmado en qué destino se tomó cada una.
